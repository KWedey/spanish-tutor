# L1 Interference Protocol

Loaded when: Introducing a new grammar concept during a session.

## Protocol

When introducing any new concept:

1. **Before the lesson:** Read `curriculum/l1-interference.yaml` and find entries tagged to this concept (`preempt_at` field).

2. **During explanation:** Proactively address the English habit:
   - "In English, you'd say 'I am tired' with 'am.' In Spanish, being tired is a temporary state, so we use estar, not ser."
   - Frame it as a contrast, not a warning. The learner should understand WHY the English habit exists and WHY Spanish works differently.

3. **During controlled practice:** Specifically drill the contrast between the English pattern and the Spanish pattern. Include exercises where the English instinct would lead to the wrong answer.

4. **In the session log:** Note any L1 interference errors separately from developmental errors. They need different treatment:
   - **Developmental errors** resolve with practice and input.
   - **L1 interference errors** need explicit contrast teaching and targeted practice.
   - **Fossilized L1 errors** (persisted 5+ sessions) need intensive intervention: awareness-raising, over-correction period, explicit monitoring.

## Error Escalation

If the same L1 interference error appears 3+ sessions in a row:
1. Try a different explanation approach
2. Create a dedicated contrast drill
3. Assign homework specifically targeting the contrast
4. Consider visual aids or mnemonics

If it persists beyond 5+ sessions:
1. Mark as "fossilized risk" in skill-map notes
2. Implement an over-correction period: explicitly practice the correct form 10+ times per session
3. Ask the learner to self-monitor for this specific error in their daily self-narration
